# Wireshark Network Traffic Analysis

## Project Overview
This project explores basic network traffic analysis using Wireshark. The goal is to understand how devices communicate over a network by observing captured packets.

## Tools Used
- Wireshark
- Windows

## Concepts Explored
- Network packets
- Source and destination IP addresses
- DNS protocol
- TCP, UDP and other network protocols

## Practical Work
- Captured network traffic using Wireshark.
- Applied the DNS display filter.
- Observed DNS packets.
- Identified packet source information.

## Learning Outcomes
- Understood how network communication can be observed.
- Learned the basic structure of a network packet.
- Started identifying common network protocols.

## Project Status
Beginner-level practical project — currently in progress.
